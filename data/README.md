# Dataset

## Source

The project uses the [Credit Card Fraud Detection dataset on Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud). This repository does not include the dataset.

## Expected file

- Filename: `creditcard.csv`
- Location: `data/raw/creditcard.csv`

## Obtain the dataset

1. Sign in to Kaggle and open the [dataset page](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud).
2. Accept any applicable Kaggle terms and download the dataset using Kaggle's download option.
3. Extract `creditcard.csv` into `data/raw/`.

Raw and processed datasets are excluded from Git to avoid committing large data files and to respect dataset distribution terms. Keep the downloaded file local; do not commit it.
