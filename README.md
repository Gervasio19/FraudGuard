# FraudGuard

FraudGuard is an educational portfolio project exploring machine learning for financial fraud detection. The project is under development; no analysis, models, or results are available yet.

## Business problem

Payment fraud creates financial losses and operational costs. This project will explore how transaction data can support fraud detection while accounting for the challenges of highly imbalanced data.

## Objectives

- Establish a reproducible project structure and development environment.
- Explore the selected public credit card fraud dataset in a later phase.
- Develop and evaluate fraud detection approaches in subsequent phases.
- Present findings and project outputs clearly.

## Dataset

The planned dataset is the [Credit Card Fraud Detection dataset on Kaggle](https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud). It has not been downloaded or analyzed. See [data/README.md](data/README.md) for local placement instructions.

## Technology stack

Development environment: Python 3.14.6. Initial dependencies: pandas, NumPy, Matplotlib, Seaborn, Jupyter, and ipykernel.

## Roadmap

1. Project initialization (current phase).
2. Dataset exploration and quality assessment.
3. Data preparation and feature engineering.
4. Model development and evaluation.
5. Results communication and project presentation.

## Status

**Under development — Phase 1: Project Initialization.** No data analysis or machine learning functionality has been implemented.
